第一次使用，三步就绪。

安装 → 配置 → 创作
  1. 01

    安装桌面客户端

    选择与你电脑匹配的版本，下载后按系统正常安装流程完成安装。

  2. 02

    填入自己的 API Key

    默认 API 为 YITOKEN。到 官网获取自己的 API Key，填入客户端设置并同步模型。客户端不附赠运营方 Key。

  3. 03

    创作片段，导出整片

    制作剧本与分镜、生成素材，把视频放入项目时间线排序，再合成为 MP4。

主动 AI 生成按本人账户额度计费；本机拼接已有视频不新增 AI 生成费用。
