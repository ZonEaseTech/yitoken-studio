使用步骤

安装客户端 → 新建项目 → 在设置中填写本人 Key → 同步模型
    → 剧本 / 分镜 / 角色 / 图片 / 视频创作（主动生成可能计费）
    → 将视频放入当前项目时间线并排序 → 导出页：合成整片 MP4
    → 选择新的本地保存位置 → 等待实际验证成功 → 打开保存位置
  • 整片输出：720p / 1080p、16:9 / 9:16、30fps、H.264 / AAC；保留原音，无音轨补静音，不同比例留黑边、不拉伸。
  • 第一版不含字幕、BGM混音、转场、裁剪、多轨编辑或在线项目分享。
  • 最多200段，单段10分钟，总长2小时；每源512MiB、源文件合计2GiB。取消不删原素材，不覆盖已有输出。
  • 参考素材会发送给所选AI服务商；公开图床默认关闭，开启前须明确同意，勿上传未授权或机密内容。
  • 系统安全加密不可用时，Key仅会话有效；不会回退明文持久化。网络提交结果未知时不自动重复提交，先核对后台任务。
