三步开始创作

安装 → 配置 → 创作与导出

  1. 01下载安装

    选择与你电脑匹配的包，下载完成后自行核验 SHA-256，再按系统正常安装流程安装。

  2. 02填写本人 Key

    默认 API 为 YITOKEN。到 YITOKEN 官网获取自己的 API Key，在客户端设置中填写并同步模型；客户端不附赠运营方 Key。

  3. 03创作并合成整片

    新建项目，完成剧本 / 分镜与片段生成；将视频放入当前项目时间线，排序后在导出页合成整片 MP4。

主动 AI 生成可能按本人账户额度计费；本机拼接已有视频不新增 AI 生成费用。
